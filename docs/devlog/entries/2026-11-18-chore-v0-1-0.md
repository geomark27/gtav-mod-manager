# Prepare release 0.1.0

## What changes

- The updater signing key is configured: the public key is in `tauri.conf.json` and the
  private key is the `TAURI_SIGNING_PRIVATE_KEY` repository secret, so release builds produce
  signed updates that installed versions can verify.
- `CHANGELOG.md` and the devlog are closed for 0.1.0 (`docs/devlog/releases/v0.1.0.md`).
- `make pr` works again: an unescaped `#` in the Makefile cut the repo-URL helper and broke the
  whole recipe with a shell syntax error.

## Why

First public release: the release workflow refuses to run without the updater key, and the
release notes come from the `[0.1.0]` CHANGELOG section.

## Files and areas

- `apps/desktop/src-tauri/tauri.conf.json` (updater `pubkey`)
- `CHANGELOG.md`, `docs/devlog/`, `Makefile`

## How to test

- `DRY_RUN=1 make release` after promotion shows tag `v0.1.0` with the CHANGELOG notes.
- After the release: the installer and `latest.json` are attached to the GitHub release.

## Notes and follow-ups

- This entry was created after closing 0.1.0, so it is listed with the next version.
- The private key must be backed up outside the machine (password manager).
